# Password Strength Tester

A simple password strength checker made with Python and Tkinter.

## What it does

- Checks if a password is weak, medium, or strong
- Explains why a password may be weak
- Lets you show or hide the password
- Runs only on your computer
- Does not save or send your password

## How to run

1. Make sure Python is installed.
2. Download this project.
3. Open the project folder.
4. Open Command Prompt or Terminal in that folder.
5. Run:

    python main.py

If that does not work, try:

    python3 main.py

The program should then open.

## Requirements

- Python 3
- Tkinter

Tkinter usually comes with Python.
